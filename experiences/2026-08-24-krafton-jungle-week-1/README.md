# [EXPERIENCE] 크래프톤 정글 첫 주

크래프톤 정글에 입소한 첫 주의 목표는 분명했다. 새로운 팀원들과 짧은 기간 안에 의미 있는 결과물을 만들고, 그 과정에 깊이 몰입해 보는 것이었다.

이번에는 ChatGPT나 Claude 같은 코드 에이전트에 기대지 않고 직접 구현해 보기로 했다. 문법을 익히고 알고리즘을 고민하며, 막힌 부분을 디버깅하고 작성한 코드를 스스로 검증하는 힘을 기르고 싶었다.

## Learning Goal

- 새로운 팀원과 짧은 기간 안에 의미 있는 결과물 만들기
- 문제를 붙잡고 깊이 빠져드는 몰입 경험하기
- 직접 구현하며 문법, 알고리즘, 디버깅, 코드 검증 역량 기르기

## Learning Keyword

- 팀 프로젝트
- 동료 학습
- 와이어프레임
- SSR
- 세션
- JWT
