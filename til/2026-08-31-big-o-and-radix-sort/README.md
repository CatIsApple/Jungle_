## 7번 문제 · Complexity

처음으로 Big O 표기법을 알게 되었고, 시간 복잡도와 공간 복잡도에 대해서 배웠다.

처음에는 Big O가 무엇인지, 그 안에 나오는 `O(n^2)`, `O(n log n)`, `O(n)`, `O(1)` 등이 무엇을 의미하는지도 몰랐다.

## 4시까지 막혀 있던 풀이

4시까지 시행착오만 반복하며 7-1 브루트포스 문제만 해결했다.

그러다가 팀원분께서 기초적인 내용을 알려주셨고, 그 도움을 바탕으로 7-2의 `O(n log n)` 풀이도 해결했다.

## Radix Sort를 구현하며

마지막으로 문제에서 `O(n)` 풀이를 위해 사용한 선형 정렬 방식인 Radix Sort를 공부했다.

처음부터 끝까지 직접 Radix Sort를 만들고 싶었다. 하지만 아직 내 파이썬 문법이 그 정도 수준은 아니었기 때문에 `update()`, `extend()`, `add()`, `set()`, `lstrip()` 등 여러 함수와 문법을 AI에게 물어보며 코드를 작성했다.

> 일단 지금으로서는 이것을 완벽하게 이해했고, 내 머릿속에서 나온 코드를 그대로 옮겼다는 데 의미를 둔다. 하나씩 발전해 나가자.

## 도움을 받아도 남은 것

원래라면 이 모든 문제를 풀면서 AI를 아예 사용하지 않을 예정이었다. 하지만 몇 시간째 진도조차 나가지 않았기에 AI와 팀원분의 도움을 조금 받았다.

그 과정에서 여러 가지를 배웠다.

- `"010"`을 `int`로 변환하면 앞의 `0`이 사라져 `10`이 된다는 것
- `update()`, `extend()`, `add()`, `set()`, `lstrip()`의 사용법
- 로직을 어떤 방식으로 처리하고 문제를 어떻게 해결해야 하는지
- Big O 표기법을 통한 시간 복잡도와 공간 복잡도
- `O(1)`, `O(n)`, `O(n^2)`, `O(n log n)`처럼 서로 다른 복잡도와 정렬 접근 방식
