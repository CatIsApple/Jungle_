## 이번 주 학습

이번 주에는 총 10개 문제의 풀이를 작성하며 Python 기초 문법부터 완전 탐색, 재귀, 백트래킹, 시간 복잡도, 이분 탐색, 분할 정복과 머지 정렬까지 학습했다.

힌트와 정답을 먼저 보지 않고 문제를 직접 풀었고, 구현이 막히는 지점에서는 실행 흐름과 인덱스의 변화를 하나씩 확인했다.

## 주요 문제

| 문제 | 학습 내용 |
| --- | --- |
| Basic 01 · `01_string.py` | 회문 판별 |
| Basic 02 · `02_array.py` | 2차원 배열 90도 회전 |
| Basic 03 · `03_python_dict.py` | 리스트와 딕셔너리로 평균 이상 학생 찾기 |
| Basic 04 · `04_brute_force.py` | 완전 탐색으로 두 수의 합 찾기 |
| Basic 05 · `05_recursion.py` | 재귀로 팩토리얼과 피보나치 구현 |
| Basic 06 · `06_backtracking.py` | 백트래킹으로 조합 생성 |
| Basic 07 · `07_complexity.py` | 세 가지 복잡도로 중복 원소 탐색 |
| Basic 10 · `10_binary_search.py` | 이분 탐색 구현 |
| Basic 11 · `11_divide_conquer.py` | 분할 정복으로 배열의 최댓값 찾기 |
| Advanced 02 · `02_merge_sort.py` | 머지 정렬 구현 |

## 이번 주에 배운 것

문자열과 배열 문제를 풀며 Python의 기본 문법과 인덱스 처리 방식을 익혔다. 딕셔너리 문제에서는 컴프리헨션을 활용했고, 완전 탐색 문제에서는 이중 반복문의 실행 순서를 직접 따라가며 로직을 구현했다.

재귀와 백트래킹에서는 함수 호출이 쌓이고 돌아오는 구조를 학습했다. 특히 `06_backtracking.py`는 14시간 넘게 붙잡고 해결하면서 재귀 흐름과 종료 조건을 더 깊게 이해할 수 있었다.

Complexity 문제를 통해 Big O와 시간 복잡도·공간 복잡도의 관계를 처음 배웠다. 7-1은 브루트포스, 7-2는 `set()`, 7-3은 기수 정렬을 활용해 풀었다. 기수 정렬을 구현하면서 `zfill()`, `extend()`, `set()` 등 Python 내장 함수의 활용 방식도 함께 익혔다.

이후 정렬된 배열에서 탐색 범위를 절반씩 줄이는 이분 탐색을 구현했다. 분할 정복으로 배열의 최댓값을 찾고, 배열을 나눈 뒤 다시 병합하는 머지 정렬도 학습했다.
