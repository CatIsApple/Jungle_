## 이번 주 학습

이번 주에는 알고리즘 기초 문제와 시간 복잡도를 집중적으로 공부했다. AI와 힌트를 먼저 보지 않고 백지에서 문제를 푸는 방식을 선택했고, 한 문제를 이해할 때까지 오래 붙잡았다.

기본적으로 한 문제를 푸는 데 6시간 정도 걸렸고, 백트래킹 문제 하나는 14시간 넘게 풀었다. 어려운 내용이 많아 내 실력에 실망하기도 했지만, 정답을 따라가지 않고 직접 로직을 만들며 이해하는 경험을 쌓았다.

## 주요 문제

| 구분 | 학습 내용 |
| --- | --- |
| `01_string.py` | 문자열 뒤집기 |
| `02_array.py` | N × N 배열 90도 회전과 인덱스 이동 |
| `03_python_dict.py` | 딕셔너리와 컴프리헨션 활용 |
| `04_brute_force.py` | 이중 반복문을 이용한 완전 탐색 |
| `05_recursion.py` | 재귀 호출이 쌓이고 돌아오는 흐름 |
| `06_backtracking.py` | 재귀 구조를 이용한 백트래킹 |
| Complexity 7-1 | 브루트포스 풀이 |
| Complexity 7-2 | `set()`을 활용한 `O(n log n)` 풀이 |
| Complexity 7-3 | 기수 정렬과 `O(n)` 풀이 |

문제를 풀면서 문자열과 배열부터 완전 탐색, 재귀, 백트래킹까지 이어서 학습했다. 이후 Big O와 시간·공간 복잡도의 관계를 처음 익혔고, 기수 정렬을 직접 코드로 옮기며 파이썬 내장 함수의 활용 방식도 배웠다.

## 학습 방식 점검

한 문제에 많은 시간을 쓰다 보니 이 방식이 맞는지 의문이 들었다. 다른 사람들의 학습 방식을 보며 나도 방법을 바꿔야 하는지 고민했고, 윤은선 코치님께 직접 여쭤봤다.

> “제가 하는 방식이 맞는 방식일까요?”

> “잘하고 있다. 그런 걸 원했다.”

내 선택이 근거 없는 고집일 수 있다고 생각했지만, 코치님의 답변을 들은 뒤에는 의심하지 않기로 했다. 앞으로도 쉽게 답을 찾기보다 끝까지 파고들며 문제를 이해하는 태도를 유지할 것이다.
